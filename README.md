# StepFree LPU

**Know your route. Move with confidence.**

Student design-thinking prototype (P12 – The Ramp That Ends at a Step) for Lovely Professional University.
Helps people explore step-free campus routes, check route conditions, and report barriers.

> **Prototype demo.** Route times, distances, ramp/lift notes, reports and dashboard figures are sample data and have not been verified on site.
> Built from an early, exploratory survey (22 responses). Not an official LPU service.

## Run
It is a single self-contained `index.html` file. Open it in a browser, or host it with GitHub Pages.

## Pages
Home · Route planner · Route detail · Report a barrier · Reports · How it works · About · Log in (demo only, nothing is stored)
